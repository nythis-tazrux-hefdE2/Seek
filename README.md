# Seek

Seek 是可自行部署的 AI 技术情报研究助手。提交研究主题、事件时间窗口和来源要求后，助手组织并行调研与独立核查，生成可预览、下载的 HTML 报告。

## 研究能力

- 分派至少两项独立调研，按精确任务回收结果，再交由另一子会话核查。
- 对照本次取得的网页证据检查来源、摘录及日期，保留冲突、未知与证据缺口。
- 支持研究材料附件、流式过程、人工回答与工具审批、取消一轮及停止协作树。
- 在本地保存研究会话、执行状态、调用记录、用量与反馈，支持刷新后回读。

来源一致性检查不能代替人的事实判断。研究质量取决于模型、来源质量及外部服务可用性。

## 快速启动

准备 Docker Engine、Docker Compose v2、Python 3，以及模型和搜索服务凭据。在仓库根目录运行：

```bash
bash scripts/init.sh
```

初始化器生成私有 `.env` 和独立实例密钥。填写 `DEEPSEEK_API_KEY`、`TAVILY_API_KEY`，再执行：

```bash
docker compose config --quiet
docker compose up -d --build
curl --fail http://localhost:35050/api/system/ready
```

返回 `status: ready` 后，打开 <http://localhost:35173>，按页面提示创建首位管理员并登录。在“设置 → 模型服务”启用模型服务、确认模型并测试连接；在基本设置选择可用的默认对话与快速响应模型，在网络搜索设置检查供应商和凭据。

首次构建需要下载依赖和镜像；模型和搜索调用可能产生供应商费用。已有部署继续使用对应的私有配置与数据，初始化器保留已有非空值。完整启动、备份及故障处理见[部署说明](docs/deployment.md)，环境变量及可选服务见[配置参考](docs/configuration.md)。

## 提交研究并读取报告

```text
主题：比较 LangGraph 与 AutoGen 的持久化与人工介入机制。
事件/版本窗口：填写明确的起止日期。
来源要求：优先原始论文、官方文档和发布说明。
交付：两项独立调研、精确结果回收、另一会话独立核查、正式 HTML 报告。
保留冲突、未知及无法确认的日期。
```

过程视图展示子任务和工具调用。正式报告卡片支持 HTML 预览与下载；修改过的报告不能沿用原检查结果。操作步骤和报告边界见[研究使用说明](docs/research.md)。

默认产品聚焦技术研究；知识库、图谱、定时任务和通用扩展管理不属于运行能力。PDF/OCR 和远端 Langfuse 为可选配置。默认 Compose 面向本地运行，公网部署需自行配置入口、HTTPS、访问范围、备份及协议模板。
